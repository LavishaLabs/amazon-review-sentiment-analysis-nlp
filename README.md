# Amazon Review Sentiment Analysis using NLP
## Project Overview
This project builds an automated Sentiment Analysis System capable of
classifying Amazon customer reviews into Positive and Negative sentiments using
Natural Language Processing (NLP) and Machine Learning.
---
## Business Objective
The system helps e-commerce companies:
- Monitor customer satisfaction
- Detect negative product trends
- Improve product quality
- Resolve complaints faster
---
## Dataset Information
- Total Reviews: 10,000
- Labels:
- pos → Positive Review
- neg → Negative Review
---
## Technologies Used
- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- Matplotlib
- WordCloud
---
## NLP Workflow
1. Data Cleaning
2. Text Preprocessing
3. Stopword Removal
4. Lemmatization
5. TF-IDF Vectorization
6. Model Training
7. Evaluation
---
## Models Used
- Logistic Regression
- Support Vector Machine (SVM)
---
## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
---
## Results
The models successfully classified customer reviews with strong accuracy and
robust sentiment prediction performance.
